# MsSystems - Backend (Sistema de Gestão de Controle de Recepção e Armazenagem)

API REST desenvolvida para o gerenciamento e controle industrial de recepção, pesagem de matérias-primas, triagem de qualidade, gestão de lotes e rastreabilidade de estoque.

---

## 🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando as melhores práticas do ecossistema Java moderno:

* **Java 21 (LTS)**
* **Spring Boot (v4.1.1)**
* **Spring Web** (Construção de APIs RESTful)
* **Spring Data JPA & Hibernate** (Persistência e Mapeamento Objeto-Relacional)
* **Spring Security** (Autenticação e Controle de Acesso)
* **Bean Validation** (Validação rigorosa de dados industriais)
* **PostgreSQL** (Banco de dados relacional principal)
* **Maven** (Gerenciamento de dependências e build)

---

## 📋 Pré-requisitos

Certifique-se de ter as seguintes ferramentas instaladas na sua máquina antes de iniciar:

* [JDK 21](https://adoptium.net/) ou superior
* [Maven](https://maven.apache.org/) (ou utilize o `mvnw` incluso no projeto)
* [PostgreSQL](https://www.postgresql.org/) em execução
